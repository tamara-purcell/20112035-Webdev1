About my Website

This website allows users to create and manage their own Pokémon catalogue.

JSON Array of Objects

This Pokémon catalogue uses an array of objects. Each object represents one Pokémon and stores information about it.

Each Pokémon record contains:

  • Name
  • Pokédex Number
  • Type
  • Generation
  • Level
  • Shiny Status
  • Legendary Status
  • Image

I used Javascript to display Pokémon records, add new Pokémon and delete Pokémon. The records are saved in localStorage so they still are available even when the page is reopened.
